# Changelog

## 3.0.0-beta.1 — GooseRoute
- Rebranded from PinShift with goose-on-pin icon and GooseRoute name.
- Added genuine walk, cycle and drive route preview using public OSRM profiles.
- Added target duration and fixed average-speed controls.
- Added limited waypoint-detour search for routes near the requested trip distance.
- Map now shows the network route before playback.
- Location-service playback follows route coordinates, with gentle speed variation.
- Public installation instructions, sharing and privacy documentation.
