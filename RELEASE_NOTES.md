# GooseRoute 3.0 beta 1

GooseRoute (formerly PinShift) gives Android testers a detailed map picker, location favourites and road-network route previews.

**New:** walking, cycling and driving profiles; target duration in minutes; adjustable trip-average speed; route matching via waypoint detours; route preview; path-following simulated motion with gentle speed variation; goose-branded logo and updated interface.

**Install:** Download `GooseRoute-beta.apk` and install it on Android 13+, then select GooseRoute under Developer options → Select mock location app.

**Beta warnings:** This package is a debug-signed beta. Upgrading from a previous build may require uninstalling it. The routing provider is a rate-limited public community demo; service availability and exact duration matches are not guaranteed. Android marks mock locations, and other apps can detect or ignore them. Tested in GitHub CI for compilation only.
