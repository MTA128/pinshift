# Helping improve GooseRoute

Thanks for testing GooseRoute. Open a GitHub issue with your Android version, phone model, expected result, actual result, and any **redacted** logs. Never share your home GPS coordinates publicly.

Suggested priorities:
1. Accessibility and smaller-screen layouts.
2. Route caching and proper hosted routing infrastructure.
3. Improved route matching for target duration.
4. Stable, documented release signing and seamless upgrades.
5. Instrumented device testing and other Android versions.

Do not submit code designed to conceal mock-location status from third-party apps or defeat device integrity checks.
