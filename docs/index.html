Install in a few steps

  1. Download the APK from the latest GitHub release.
  2. Install it with Samsung My Files / Android Files.
  3. Select GooseRoute under Developer options → Select mock location app.
  4. Pick coordinates, preview a route and start testing.
Important: GooseRoute is a beta simulator, not a way to hide mock-location status from other apps. Android labels mock locations, and third-party services may detect or ignore them. Route previews use a rate-limited public routing demonstration server; availability and exact requested durations are not guaranteed. Beta APKs may be signed with different debug keys across builds.
